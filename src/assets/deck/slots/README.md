Drop images (or short .mp4 loops) here for the deck at /projectppt.

Name each file after its slot, e.g. `study-buddy.webp` or `design-team.jpg`; the slot picks
it up on the next build. Slot names, what goes in each and the suggested shape are listed
in presentation/VISUAL_SLOTS.md, and every empty slot shows its name on the slide itself.
